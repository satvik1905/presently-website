Presently is a student check-in system built for Kumon learning centers. Core features: fast kiosk check-in (QR/PIN), live board showing who's present with timers, automatic SMS notifications to parents on arrival/departure, and searchable attendance records.

**Why:** The product solves the "busy hour" chaos at Kumon centers — staff need to track dozens of students checking in/out while fielding parent calls.

**How to apply:** The website is a single-page marketing/landing site. The primary CTA is "Book a demo." Design language uses blue (#2563EB) as the primary accent, Geist font, and clean card-based UI with mock product screenshots. Target audience is Kumon center owners/managers.
